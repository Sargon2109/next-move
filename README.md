# Next Move

**Your Toyota's next move, figured out together.**

Built at HackUTD 2026 (Zero Day) for the **Toyota Financial Services** challenge, with a backend that runs entirely on **SpacetimeDB**.

> "Given my situation today, what's the smartest next move for me and my Toyota?"

Next Move takes a customer's vehicle, contract, and life situation and lays out every real option side by side (return it, buy it out, refinance, upgrade) with honest numbers. When the customer wants help, a Toyota Financial specialist joins the **same screen, live**: slider changes, offers, and decisions sync instantly between both people.

## What it does

- **Personalize:** loads a customer profile, vehicle, and lease or loan (synthetic data for 3 customers).
- **Simplify:** every option shows monthly payment, due now, and a 3-year net cost, plus pros, cons, and the assumptions behind the math.
- **Guide:** options are ranked by life fit, then budget, then 3-year cost. The top pick is labeled with a confidence level, and every option ends in a clear next step (self-service, specialist follow-up, or an applied offer).
- **Value:** a specialist console with a live queue, "moments that matter" found by a scheduled scan (lease ending soon, positive equity, mileage overage, improved credit), and eligible offers that update the customer's numbers the moment they accept.
- **Responsible AI:** all numbers come from deterministic math in the database. The AI only explains the ranked options in plain English and never generates numbers. If no AI key is set, a rule-based explanation is shown instead.

## Why SpacetimeDB

The whole backend is a SpacetimeDB module (`spacetimedb/src`):

| Piece | SpacetimeDB feature |
| --- | --- |
| Customers, rooms, quotes, offers, activity | Tables, subscribed live by both screens |
| Option math on every slider move | Reducers (`update_inputs`, `respond_offer`) recompute quotes in the same transaction |
| Shared screen between customer and specialist | Client subscriptions: every change is pushed to everyone in the room |
| "Moments that matter" queue | Scheduled reducer (`scan_moments`) runs every 30 seconds |
| AI explanation | Procedure (`explain_room`) calls an OpenAI-compatible LLM with `ctx.http.fetch`, then writes the result to a table |
| API key | Private table (`llm_config`), never sent to clients |

There is no other server. The React app talks only to SpacetimeDB.

## Project layout

```
spacetimedb/src/index.ts     tables, reducers, scheduled scan, AI procedure
spacetimedb/src/finance.ts   all payment, equity, and ranking math
spacetimedb/src/seed.ts      synthetic customers and eligible offers
spacetimedb/src/llm.ts       OpenAI-compatible chat call
src/CustomerView.tsx         customer screen
src/RepView.tsx              specialist console
src/components.tsx           shared UI (option cards, sliders, explanation)
src/module_bindings/         generated by `spacetime generate`
```

## Run it

Requirements: Node 20+, the [SpacetimeDB CLI](https://spacetimedb.com/install), and `spacetime login`.

```bash
npm install
(cd spacetimedb && npm install)

# publish the backend to SpacetimeDB cloud (name comes from spacetime.json)
spacetime publish

# start the web app
npm run dev
```

Open `http://localhost:5173`. Use **I'm a customer** on one laptop and **I'm a Toyota specialist** on another.

If the database name is taken, change `database` in `spacetime.json` and `VITE_SPACETIMEDB_DB_NAME` in `.env.local` to the same new name.

### Optional: turn on the AI explanation

Any OpenAI-compatible endpoint works (NVIDIA Nemotron, OpenAI, OpenRouter):

```bash
spacetime call set_llm_config '"https://integrate.api.nvidia.com/v1/chat/completions"' '"YOUR_API_KEY"' '"MODEL_ID"'
```

The first identity to call this becomes the admin. The key lives in a private table.

### After changing the backend

```bash
spacetime publish
npm run bindings   # regenerates src/module_bindings
```

## Demo script (2 minutes)

1. Customer laptop: open as **Maya** (RAV4 lease, baby on the way, 3,476 miles over pace).
2. Point out that the best fit is the Grand Highlander lease, but it's **$115/mo over budget** (low confidence).
3. Click **Bring in a specialist**. On the specialist laptop, Maya appears in **Waiting for you**. Click **Join**.
4. Specialist sends **$1,000 loyalty cash**. Maya taps **Apply it**.
5. Maya drags the down payment to **$3,000**. Both screens update instantly, and the lease now fits her budget with **high confidence**.
6. Click **Explain it like a person**, then **Choose this**. The specialist sees the decision live.

All customer data is synthetic.
